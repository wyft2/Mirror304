# 镜子里的304 · 网页解密游戏

变格悬疑 / 微恐 / 网络档案调查。玩家以许砚整理的「青石里旧楼档案」网站为入口，
在建筑资料、住户记录、旧照片、声音档案之间交叉比对，拼出七位档案密钥，
最后找回镜中消失者的姓名，或打开那扇门。

- 游戏时长：约 1–2 小时
- 推荐设备：手机或桌面浏览器，建议佩戴耳机
- 技术形态：纯静态网站，无构建步骤、无外部依赖、无网络请求
- 入口文件：`index.html`

## 运行方式

### 直接打开

双击 `index.html`。现代 Chrome / Edge / Safari 可以直接运行完整的解谜流程。

### 推荐的本地服务器

在项目目录执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8765/>。

也可以运行 `serve.sh`（macOS / Linux）。使用本地服务器时，`localStorage`
行为最稳定。

### 部署

项目可直接上传到任意静态站点托管（GitHub Pages、Cloudflare Pages、Nginx 目录等）。
不需要后端。页面之间使用相对路径，放在子目录中也能正常工作。

## 玩家可见结构

1. `index.html` 青石里旧楼档案（四个入口 + 页脚未整理资料）
2. `building.html` 青石里三号楼建筑档案（图纸 / 维修单 / 手绘草图）
3. `residents.html` 三号楼住户登记表（现行登记 / 1999旧表 / 小学材料）
4. `photos.html` 许家旧照片（四张照片，可翻到背面、放大镜中门牌）
5. `audio.html` 2001年6月17日录音记录（三段可播放录音 + 文字稿）
6. `archive.html` 许砚的私人记录（七位密钥 → 姓名确认 → 结局分流）
7. `ending-remember.html` 结局 01 · 记得她
8. `ending-door.html` 结局 03 · 打开门

结局 02 不是独立页面：在姓名栏输入错误姓名后，错误提示与 `UNKNOWN_AUDIO.WAV`
中新增的声音会出现在第六页，玩家可以继续调查。

## 交互与状态

- 档案碎片由「调查手记」自动收集；进度保存在浏览器 `localStorage`。
- 存储键：`qsl304.archive.v1`
- 持久化字段：`clues`、`unlocked`、`remembered`、`doorOpened`、`footerSeen`
- 页脚或结局画面中的「恢复初始档案 / 重新开始调查」会清除全部进度。
- 打开隐藏结局后，`residents.html` 会在之后每次访问时显示改写后的登记表。
- 结局页会校验对应状态；直接访问未解锁的结局页会退回 `archive.html`。

## 制作说明

- 所有照片与建筑图均为本项目自制 SVG。网页在原始 SVG 上叠加纸张、噪点与胶片质感。
- 三段磁带、结局录音、错误姓名录音由离线音频合成流程制作，环境底噪、敲击与
  磁带效果单独混音。播放器的时间标签与转场时间对齐。
- 人声只使用剧本对白，没有额外添加剧情信息。
- 使用 Web Audio 生成少量 UI 反馈音（敲击 / 低频）。所有音频都由用户交互触发，
  不会自动循环播放。
- 全站无第三方脚本、无分析统计、无远程请求。

## 无障碍与兼容性

- 主要交互按钮均为原生 `<button>`，弹窗使用原生 `<dialog>`。
- 视觉内容有替代文本；照片背面与声音文字稿都可以阅读。
- 支持键盘操作：Esc 关闭弹窗，方向键切换照片，录音进度条支持方向键 / Home / End。
- 遵循 `prefers-reduced-motion`。
- 现代 Chromium / Firefox / Safari 可用；`dialog` 与 `localStorage` 需要较新的浏览器。

## 谜底

镜子后的 304 室真实存在，但只能通过三楼走廊尽头的镜面进入。进入者会逐渐从
他人的记忆中消失；照片、文字和录音不会变，所以证据仍然指向许棠。她仍能敲击
镜面或门，等待有人记起她的名字。玩家通过档案推导出的不是「她是否存在」，
而是「为什么所有人都不记得一个仍然留在照片里的人」。

## 结局条件

- **结局 01 · 记得她**：在姓名栏提交 `许棠`。
  显示新录音 → 三下敲击 → 自动跳转 → 全家福清晰化 → 许砚留言 → 黑屏 →
  「这一次，门外有人记得你。」
- **结局 02 · 错误的名字**：提交其他姓名。
  显示「没有找到对应的住户记录。请重新核对档案。」；`UNKNOWN_AUDIO.WAV`
  变为可播放并出现「你认错人了。她还在这里。」。玩家可以继续。
- **结局 03 · 打开门（隐藏）**：在姓名栏下方点击「打开门」并确认。
  走廊照片 → 无许棠、304 半开门 → 档案模拟刷新 → 302 只剩父母、304 登记许砚
  （入住 2001-06-17 02:13，退房未记录）→
  「现在，轮到你留下来陪她了。」。该状态持久化。
